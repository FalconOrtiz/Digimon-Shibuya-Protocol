# Digimon: Shibuya Protocol

Autor: Falcon Ortiz (FalconOrtiz).

Repositorio: https://github.com/FalconOrtiz/Digimon-Shibuya-Protocol

Fan game FPS en el cruce de Shibuya. Motor: Vite + Three.js. El contrato del motor está en `ARCHITECTURE.md`.

```
npm install
npm run dev
```

El juego abre en http://127.0.0.1:5173.
